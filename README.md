# buugetschedule

An independent, responsive timetable website for Burapha University students.

## Stack

- Next.js App Router
- React
- TypeScript
- CSS

## Development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the application.

## Project status

The initial Next.js foundation and responsive welcome screen are in place. The REG BUU authentication and timetable integration have **not** been implemented yet. No mock timetable data or simulated authentication is used as a substitute for the real integration.

See [docs/MASTER_PROMPT.md](docs/MASTER_PROMPT.md) for the approved product requirements and acceptance criteria.

## Important

This is an independent student project and is not an official Burapha University service. REG BUU credentials must never be stored by this application.
